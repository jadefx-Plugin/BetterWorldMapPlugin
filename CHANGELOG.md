# Changelog

## 1.2.0.0

- Adopt PrettyUI 1.3.3 automatic component-ID allocation for windows and custom artwork; batch initial construction.
- Replace duplicate custom resize handles with PrettyUI resizing and save position through its drag-finished callback. Preserve 520x360 minimum size and header control click areas.
- Keep plugin windows movable independently of the native interface lock.
- Add optional native window-background transparency, composed with existing normal/walking opacity.
- Use the dependency’s lazy tooltip lifecycle and retain efficient map dropdown filtering; reset scroll explicitly on changed search results.
- Destroy the searchable map dropdown’s sibling overlay on shutdown to prevent retained controls across reloads.

## 1.1.0.2

- Refresh populated monster-drop tables from current Wiki revisions and verify 138 November 23 rebalance change groups across 196 item rows.
- Add Ghrazi Blood Knights drops, 33 inventory icons, published normal/enrage rates, pet thresholds and a Crimson Gate reference pin.
- Use canonical encounter aliases so map clicks and both knights’ context-menu actions open the same table; exclude quest/non-combat Ghrazi versions.
- Preserve mode, quantity and footnote conditions in drop tooltips; keep labelled hard-mode rates separate from normal-mode corrections.
- Split generated drop data into four grouped shards and retain source/revision/date metadata.

## 1.1.0.1

- Organize runtime modules by feature under `src/` and reference tables under `data/`.
- Separate documentation, build tools, audit reports and archived source assets from upload files.
- Keep the plugin entry point and manifest at the archive root.
- Add a repeatable release packager and project-layout guide.

## 1.1.0.0

Public release version of development build 0.12.16, including map controls, terrain blending, Prifddinas, resources, travel details, and Enter-to-chat shortcut protection.

## Development history

Paths in historical entries describe the layout at that time; see `docs/PROJECT_LAYOUT.md` for current paths.

Version 0.12.2 rebuilds desert ground colours from decoded local-cache underlays using an original chroma-weighted HSL neighbourhood blend. This corrects the abrupt sand palette transition in the historical exports, rather than covering tile boundaries. Roads, scenery, water, and icons retain their existing artwork; this is not a claim of pixel-identical native rendering. Seven base chunks, the overview, and all zoom levels are updated. The original colour-pass source is dev/tools/rebuild_ground_blending.cjs; its input is decoded cache underlay/tile data, not ClueTrainer imagery or rendering code. dev/audits/ground_blending_report.json records its coverage.

Version 0.12.3 includes the rebuilt Prifddinas upper floor on the main surface atlas at x2048–2303, z3264–3455, with 91 native city pins, surface teleport visibility, and surface player-coordinate tracking. The original dev/tools/build_prifddinas.cjs composes decoded cache floor/scene data over the existing ground-floor export; it does not use another plugin’s renderer or tiles. City artwork uses floor 1; it is not a live quest-state or floor selector.

Version 0.12.4 audits the rebuilt city's pins: all 91 city records now contain their own hover cards, including named mines, fairy ring DJS, the spirit tree, gnome glider, and city portals. Seven resource cards reuse native typed resource information. Superseded ground-floor lodestone variants and the duplicate generic fairy-ring icon are hidden without renumbering original surface records. Fourteen additional teleport methods bring city coverage to 45 methods (grouped by destination), including eight attuned seed destinations, clan vexillum, three camouflage outfits, House Teleport when the house is in Prifddinas, and completionist cape. The two existing house-portal reference markers now use the placed native portal at 2168,3334. Plague's End is checked for city methods when teleport requirements filtering is enabled. See dev/audits/prif_pin_audit.json; these remain destination-area references rather than independently verified arrival tiles.

Version 0.12.5 extends the original terrain-underlay blend to the entire bundled surface atlas. All 76 base chunks were audited against mapped local cache cells, including relocated surface areas; 75 contain ground-colour corrections. Each chunk samples a 16-world-tile halo and uses the same 5-tile blend radius as the desert pass. Only recognised bare-ground colours change. Blue water, pale building outlines, transparency, overlay artwork that does not match ground colour, and the rebuilt Prifddinas rectangle are preserved. Twelve mapped cache regions have no legacy/NXT floor pair; those cells retain their existing artwork rather than receiving guessed colours. The overview and all zoom images are rebuilt from the corrected base atlas. Offline tooling: dev/tools/rebuild_world_blending.cjs, dev/tools/rebuild_ground_blending.cjs; audit and preservation metrics: dev/audits/world_blending_report.json. This is a surface-ground colour pass, not a change to underground maps or a claim of pixel-identical native rendering.

Version 0.12.6 replaces the early approximate Prifddinas teleport grid with published teleport-map coordinates. Forty-two existing city markers move; all eight district destinations are corrected consistently for charged seeds, attuned seeds and master camouflage. Other corrections cover both resource dungeons, Morvran, the quiver's separate Eluned/Islwyn and harmony-pillar arrivals, estate agent, house-portal landing, clan vexillum and upper waterfall fishing. Max Guild garden and configured tower arrivals are represented separately for each of the three existing methods. The collapsed Nature's sentinel destination is split into yew, magic trees and ivy. City catalogue: 50 method/arrival records; total catalogue: 581. Forty-seven city records match the cited published maps; the three basic camouflage methods remain explicitly named Tower of Voices area anchors. All 531 non-city records are unchanged. See dev/audits/prif_position_audit.json. These checks compare published coordinates with map geometry; they do not claim live in-game landing captures.

Version 0.12.7 removes repeated row reconstruction when the map dropdown opens. The plugin-local src/ui/map_dropdown.lua adapter batches PrettyUI ordered-list visibility updates: unchanged opening reuses existing rows; a changed search rebuilds the result rows at most once. Repeated overlay layout callbacks reuse unchanged geometry and retain scroll position. Ordering, search, selection callbacks, resizing and empty results are preserved. The shared PrettyUI dependency is not modified; incompatible control shapes fall back to its normal path. The regression harness with the existing ordered-dropdown implementation and 48 real map choices counted 48 rebuilds / 2304 recreated rows on the previous opening path versus zero after initial widget construction with the adapter. This is an operation-count test, not a measured live-client frame-time benchmark.

Version 0.12.8 uses compact, title-only fairy-ring hover labels (for example Fairy ring - BLR), sized to their text. All 39 bundled native/city fairy-ring codes are preserved; the original navigation/access records and other tooltip layouts are unchanged.

Version 0.12.9 adds native cache-placed sub-map resources and a unified resource-dungeon entrance presentation. All 100 supported/restored sub-maps were scanned across 497 source regions with no unavailable regions. The bundled overlay contains 450 resource/utility placements across 29 maps (372 mining rocks, 56 woodcutting resources, 9 furnaces, 11 anvils and 2 deposit boxes), plus 17 resource-dungeon exit markers. Dwarven Mines includes 43 individual rocks; its resource dungeon includes 7 gold, 4 mithril, 4 achievement-gated phasmatite rocks and the deposit box. All 22 published resource dungeons have one entrance card with their entry level, access notes, contents, teleport items and separately labelled nearby travel. The 42 separate Dungeoneering-cape/Hoardstalker-ring display pins are suppressed in favour of those entrances; teleport catalogue identities remain unchanged. Nineteen bundled interiors have verified map links, and 21 additional named resource/parent maps are searchable in the map selector. Daemonheim Peninsula is already part of the surface; Dragontooth and Flesh-hatcher interiors are not bundled, but their entrance cards are included without fabricated map links. Source modules: src/dungeons/resource_dungeons.lua, data/dungeons/resource_dungeon_data.lua, data/maps/resource_submaps.lua, src/dungeons/submap_resources.lua and data/dungeons/submap_resources_data.lua. Details and sources: RESOURCE_DUNGEONS.md; dev/audits/resource_dungeon_audit.json.

Version 0.12.10 upgrades all resource-dungeon contents cards to mixed visual rows. Mining and woodcutting resources reuse the standard tool image, skill level, output item image and resource description; quantities and special access requirements remain visible. Utility icons and creature descriptions are retained. Each teleport item now has its own 32px native inventory image and requirement/usage text, including charged Hoardstalker ring artwork. Longer cards scroll through their sections, with headings kept together with a following row where space permits. Normal mining/navigation/fairy-ring card styles remain unchanged. Source data: data/dungeons/resource_dungeon_visuals_data.lua; audit: dev/audits/resource_dungeon_visuals_audit.json.

Version 0.12.11 replaces Follow me with an original crosshair button at the left of the top bar, with Follow Character hover text. Filters and zoom controls now sit on the right of that bar before the settings cog. The title and drag-hit region reserve space for these controls; resize completion retains the same clickable regions. Map minimum size is 520x360 in construction, edge resizing and saved-geometry validation. The overview shrinks as needed, catalog result height adapts to the remaining space, and overview viewport bounds refresh after overview-only size changes. Existing saved/default larger dimensions are retained until the user resizes.

Version 0.12.12 gives Follow Character, legend/key and overview buttons native toggle states with a persistent gold on / grey off indicator. The crosshair also changes colour. Follow can be switched off directly; panning automatically updates its selected appearance. Legend/overview retain their saved visibility preferences. Shortcut focus tracking now ignores initial and programmatic search-content notifications: click/key focus hooks establish editing, while submit/escape/focus loss clear it. This prevents unfocused startup search fields from blocking M. Existing configured key matching, repeat prevention, deferred search cancellation and native/chat input guards remain intact.

Version 0.12.13 addresses the built-in World Map shortcut conflict. To dedicate M to BetterWorldMap, clear the World Map assignment in RuneScape keybind settings and retain M in plugin Settings > Controls. The plugin does not consume or alter RuneScape key assignments. A valid press now retains its initial native-keyboard guard result through the deferred toggle; unrelated native UI opened by that same key no longer revokes the pending request. Chat focus, real plugin text focus and key-capture still cancel pending toggles. Inputs already restricted when the key is pressed remain blocked. One M-input diagnostic per reload records only the configured binding and boolean keyboard/chat/search focus state, never text contents.

Version 0.12.14 adds logic-tick keyboard-state polling when global KeyDown events are absent. Only a fresh configured chord press queues a toggle; holding the key does not repeat. Native events take priority when delivered. Chat, search editing, key capture and native restricted input retain their guards. M diagnostics identify event versus polling input.

Version 0.12.15 makes modern chat focus authoritative when available; CHATBOX_FOCUS is only a fallback for clients without a readable modern value. Changed M focus states are logged with individual modern/legacy values, so a console press no longer hides subsequent gameplay diagnostics. Restricted keyboard, plugin editing and capture guards remain.

Version 0.12.16 suppresses the visibility shortcut throughout an explicit Enter-to-chat keyboard session, including clients where modern chat focus remains zero. A non-repeat Enter begins/ends the session; Escape cancels it. Plugin search editing and key capture do not start chat sessions. Pending toggles are cancelled on chat entry and M diagnostics include the session state. Chat text is never accessed.
